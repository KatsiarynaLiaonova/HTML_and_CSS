# ALI BABA 3.0 — две кассы Windows и Mac владельца

Одна база находится на первой кассе Windows. Вторая касса обращается к ней по локальной сети магазина. Mac владельца подключается из магазина по той же сети или из другого места через Tailscale. Внешний сервер не требуется.

Первая касса должна быть включена, ALI BABA на ней запущена, спящий режим отключен. Закрытие программы на главной кассе останавливает доступ остальных компьютеров. Если обе кассы выключены, доступа к базе нет.

При отключении **интернета**, но работающей локальной сети и главной кассе, обе кассы продолжают продажи. Удаленный доступ с Mac в это время недоступен. Отключение роутера/локальной сети или главной кассы останавливает вторую кассу: приложение не записывает продажи в отдельную несогласованную базу.

## 1. Сначала сохранить данные

1. На компьютере с актуальными товарами и остатками сделайте резервную копию. Полностью завершите старые программы на всех компьютерах.
2. Установите версию **3.0.0** на обе Windows-кассы и Mac. Перед изменением формата базы создается `before-upgrade-…sqlite`. Старая версия 2.x не открывает новую базу формата 4; не запускайте ее после обновления.
3. Определите одну актуальную базу для первой кассы. Если нужные данные находятся на Mac, перенесите файл резервной копии на первую Windows-кассу и восстановите его через «Настройки», предварительно закрыв смены. Учетные записи подключений находятся отдельно от товарной базы и при восстановлении товаров не заменяются.
4. Данные из нескольких независимо работавших баз автоматически не объединяются. Если реальные продажи уже есть в разных базах, сначала согласуйте их перенос. Папку `.retail-store` не удаляйте.

Имена товаров, партии, старые чеки и остатки сохраняются. Прежние операции относятся к кассе 1. Тестовые продажи обновление не очищает.

## 2. Настроить главную кассу Windows

1. Обе кассы подключите к одному роутеру/локальной сети. Желательно закрепить IPv4 первой кассы в DHCP-настройках роутера, чтобы адрес не менялся.
2. Откройте ALI BABA и нажмите **«Подключение / Connection»** вверху. Альтернатива: меню «Пуск → ALI BABA → ALI BABA — Подключение».
3. Выберите **«Главная касса — общая база магазина»**.
4. Введите IPv4 первой кассы в сети магазина. Например, `192.168.1.10` — это только пример: используйте настоящий адрес своего компьютера. Программа пытается подставить найденный адрес. При необходимости его можно посмотреть в Windows командой `ipconfig`, строка «IPv4-адрес» нужного сетевого подключения.
5. Поле HTTPS-адреса Tailscale пока можно оставить пустым.
6. При первом включении общей базы задайте логин владельца и пароль от 10 символов, повторите пароль. Для последующих изменений подключения требуется существующий пароль владельца. Пароли в чат отправлять не нужно.
7. Сохраните, полностью завершите ALI BABA и откройте снова.
8. Если Windows запросит разрешение входящих подключений приложения, разрешите его для **частной сети магазина**. Для локального HTTPS используется TCP-порт 8443. Открывать этот порт в интернете/на WAN роутера не требуется.
9. Войдите как владелец. Откроются отчеты. В «Настройки → Кассиры» создайте два разных логина: один привяжите к **кассе 1**, другой — к **кассе 2**. Передайте пароли соответствующим кассирам лично.

Публичный сертификат создается здесь:

```
%USERPROFILE%\.retail-store\network\connection-certificate.pem
```

**Для второй кассы передается только `connection-certificate.pem`. `connection-key.pem` остается на главной кассе и не передается.** Публичный сертификат можно скопировать через флешку или Google Диск. При смене адреса главной кассы сертификат необходимо заменить согласованно на клиентах; лучше заранее закрепить адрес в роутере.

## 3. Настроить вторую кассу Windows

1. Установите ALI BABA 3.0.0. Откройте «Подключение / Connection».
2. Выберите **«Подключиться к главной кассе»**.
3. В поле HTTPS-адреса введите адрес первой кассы с портом 8443, например `https://192.168.1.10:8443`, заменив IP на настоящий.
4. Выберите полученный **публичный** `connection-certificate.pem`. Приложение сохранит доверенную копию в своем профиле; исходный файл из «Загрузок» после этого не требуется.
5. Сохраните, закройте и откройте ALI BABA. Войдите под логином **кассы 2**.
6. На первой кассе выйдите из учетной записи владельца и войдите под логином **кассы 1**.
7. Каждая касса открывает собственную смену и вводит свой размен. Продажи и возвраты меняют деньги ее смены, а товарный остаток общий. Возвраты через кассира доступны для чеков его кассы. Владелец видит общий отчет и может фильтровать его по кассам.

Сканер работает как USB-клавиатура с Enter после штрихкода. Сканирование доступно на кассе, в новой карточке товара и при поступлении. Сканирование при поступлении само по себе остаток не меняет — нужны количество, закупочная цена и «Сохранить».

Настройки печати в общей версии хранятся отдельно для каждой кассы. У кассира в «Настройках» доступен только шаблон печати; общие курсы, комиссии, восстановление базы и учетные записи изменяет владелец.

## 4. Подключить Mac из другого места

1. Установите [Tailscale](https://tailscale.com/download) на **главную кассу Windows и Mac**. Подключите оба устройства к одной вашей сети Tailscale. При регистрации выберите подходящий для магазина тариф по [актуальным условиям сервиса](https://tailscale.com/pricing); стоимость VPN не входит в приложение ALI BABA. Второй кассе для продаж по локальной сети Tailscale не требуется.
2. На первой Windows-кассе откройте PowerShell и выполните:

```powershell
tailscale serve --bg http://127.0.0.1:8765
```

Если Tailscale предложит разрешить HTTPS/Serve в панели аккаунта, выполните его инструкцию. Используется закрытый Tailscale Serve, а не публичный Funnel. HTTPS-адрес вида `https://имя-кассы.имя-сети.ts.net` выдает сам Tailscale; не придумывайте его.

3. Скопируйте выданный HTTPS-адрес. В ALI BABA на главной кассе откройте «Подключение», введите его в поле **«Главная касса: HTTPS-адрес Tailscale»**, введите логин/пароль владельца, сохраните и перезапустите программу. Лучше выполнить это до начала работы кассиров.
4. На Mac установите ALI BABA 3.0.0. В «Подключении» выберите **«Подключиться к главной кассе»** и введите HTTPS-адрес Tailscale. Поле публичного сертификата оставьте пустым: для адресов `.ts.net` используются доверенные публичные сертификаты.
5. Перезапустите приложение и войдите под учетной записью **владельца**. Будут доступны общие отчеты, товары и настройки. Отчеты используют общий часовой пояс магазина (по умолчанию Africa/Cairo; меняется владельцем в настройках), даже если Mac находится в другом часовом поясе. Отчеты обновляются автоматически каждые 10 секунд; есть кнопка «Обновить / Refresh».

Если Mac находится в магазине и нужен доступ без внешнего интернета, используйте локальный HTTPS-адрес главной кассы и публичный сертификат, как при подключении второй Windows-кассы.

Вместо отдельного окна на Mac можно открыть тот же HTTPS-адрес Tailscale в браузере при включенном Tailscale. Если Tailscale выключен, первая касса недоступна или в магазине нет интернета, удаленное подключение не работает. Локальные продажи от этого не зависят.

Сеть Tailscale на личных компьютерах настраивается отдельно от установщика ALI BABA. Автоматические проверки программы проверяют HTTPS между кассами, но не подтверждают настройку вашей сети Tailscale, роутера и Windows Firewall.

## 5. Исправление поворота на XP-233B

На бумаге **38 мм поперек ленты и 25 мм вдоль подачи** указывайте ширину 38 и высоту 25. В версии 3.0 поворачивается содержимое внутри неизменной страницы 38 × 25 мм: приложение больше не меняет стороны выходной страницы при четверти оборота. Это исключает прежний вариант, при котором драйвер мог автоматически компенсировать поворот.

В настройках печати своей кассы выберите сначала **90° влево** и нажмите **«Пробная этикетка»**. На ней есть отметки сторон. Сначала проверьте одну этикетку, затем считывание штрихкода. Сохраните подходящий поворот. Печатайте в масштабе 100%, без колонтитулов. Размер материала в драйвере должен соответствовать ленте. Физическую работу конкретного принтера и драйвера нужно проверить на кассовом компьютере.

## 6. Проверить перед рабочими продажами

На отдельной тестовой базе проверьте вход двух кассиров, независимое открытие/закрытие смен, продажу с обеих касс из общего остатка, отчеты владельца и отдельные настройки принтеров. Затем отключите только внешний интернет, оставив локальную сеть и главную кассу включенными: вторая касса должна продолжать работать по локальному HTTPS-адресу.

При пропавшем ответе после продажи приложение сохраняет идентификатор попытки и предлагает **«Проверить предыдущую продажу»**. Та же продажа восстанавливается без повторного списания товара и денег, в том числе после перезапуска программы. Пока результат неизвестен, не создавайте другую продажу из этой попытки.

Перед копированием/восстановлением рабочих данных завершите смены на обеих кассах. Резервная копия товарной базы не включает пароли пользователей и закрытый ключ подключения. Для аварийного восстановления главного компьютера отдельно сохраните защищенную копию его профиля на доступном только владельцу носителе.
