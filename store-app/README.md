# Nile Store — первая версия

Локальное приложение для Windows 10 Pro и macOS. Python 3.10+ и современный браузер; внешних Python-пакетов нет. Интернет для работы не требуется. Это первая тестовая версия, не готовая сертифицированная касса и не установщик Windows/macOS.

## Запуск

Скачайте папку `store-app` целиком. Установите Python 3.10 или новее с python.org, если он отсутствует.

- **Windows:** дважды нажмите `start-windows.bat` или выполните `py -3 server.py` из этой папки.
- **Mac:** в Терминале откройте эту папку и выполните `python3 server.py`. Также можно запустить `bash start-mac.command`.

Браузер откроется автоматически. Не закрывайте окно терминала до окончания работы. Для остановки — Ctrl+C. Сервер доступен только на текущем компьютере. При занятом порте: `python3 server.py --port 8766`.

## Как проверить

1. В «Настройках» установите реальные курсы: **количество EUR, EGP и RUB за один USD**. Начальные значения 1 — заглушки; продажи заблокированы до сохранения курсов.
2. В «Товарах и партиях» создайте товар, указав продажную цену в USD и единицу (шт. / кг). Карточку можно редактировать (название, штрихкод, цена); единица учета после создания не меняется, старые чеки сохраняются. Пустое поле штрихкода создает собственный код; код производителя можно ввести сканером.
3. Добавьте поступление: количество и закупочную цену **за штуку или килограмм в EGP**. Каждое поступление создает отдельную партию. Для проверки FIFO добавьте две партии одного товара с разной стоимостью.
4. На кассе сфокусируйте поле сканирования. Сканер должен работать в режиме USB HID/клавиатуры с Enter после кода. Либо найдите товар по названию. Вес вводится вручную до 0,001 кг.
5. Укажите скидки на строки и/или чек, валюту и способ оплаты. Фиксированные скидки задаются в валюте оплаты. При изменении валюты перепроверьте фиксированные скидки. Карта — только EGP, перевод — только RUB, наличные — любая из четырех валют. Для перевода требуется подтверждение кассира. Интеграции с банком нет.
6. Завершите продажу. Она записывает текущий курс и списывает партии по FIFO в одной транзакции. Если не хватает товара или наличных, продажа не сохраняется и остатки не меняются.
7. Печатайте последний чек или любой прошлый чек из отчетов. В отчетах задайте период включительно (по локальному времени компьютера), валюту оплаты, способ оплаты и независимую валюту отображения; доступны итоги и CSV.

## Расчеты

Продажная цена фиксирована в USD, закупочная цена каждой партии — в EGP. В остальных валютах текущие цены отображаются по текущим курсам. Цена продажи за единицу округляется до 2 знаков в валюте оплаты, затем рассчитываются сумма строки, скидки строки и скидка всего чека. Изменение курсов не меняет историю.

Себестоимость — сумма фактически списанных партий FIFO. В отчете себестоимость EGP и выручка переводятся в выбранную валюту по курсу **на момент каждой продажи**. Валовая прибыль = выручка после скидок − себестоимость. Это не чистая прибыль и не учет фактической конвертации наличных. Возвратов, налогов, смешанных платежей и ролей нет.

## Печать и оборудование

- XP-233B: исходная этикетка **38 × 25 мм**, размер меняется в настройках.
- XP-N160II: измеренная лента около 78 мм; начальная полезная ширина содержимого 70 мм, меняется в настройках.
- QuickScan Lite QW2100: режим клавиатуры, суффикс Enter.

Установите официальные драйверы Xprinter на Windows. Печать идет через системный диалог браузера; можно сохранить PDF на Mac. Отключите колонтитулы, задайте масштаб 100% и подходящий размер бумаги в драйвере. Штрихкод печатается в Code 39 (буквы латиницы в верхнем регистре и цифры). На маленькой этикетке длинный код может стать нечитаемым: обязательна пробная печать и проверка сканером; при необходимости увеличьте ширину этикетки. Штрихкод производителя в базе сохраняется для поиска; его печатное представление тоже Code 39.

Физическая печать, подача этикеток, арабский текст и USB-сканер здесь **не проверены**. Нужен тест на вашем оборудовании. Пока доступна печать по одной этикетке. Печать без системного диалога и массовая перепечатка — следующие доработки.

## Данные и резервные копии

База: `~/.retail-store/store.sqlite` (на Windows — папка `.retail-store` в профиле пользователя). Она сохраняется после закрытия приложения. Для отдельной тестовой базы задайте переменную `STORE_DATA_DIR` на другую папку. Не храните рабочую базу в публичной папке.

При каждом запуске создается резервная копия; дополнительная копия — кнопкой вверху. Копии находятся рядом с базой в `backups`. Переносите их на другой носитель. Восстановление: остановите приложение, сохраните текущую базу отдельно и замените `store.sqlite` выбранной копией. Автоматической очистки старых копий нет. Шаблон печати и язык хранятся в браузере и в копию SQLite не входят.

## Проверки разработчика

```sh
python3 -m unittest discover -s tests -v
```

Проверяются FIFO, дробный вес, ограничения оплаты, скидки, сохранение истории курсов, откат неуспешной продажи, резервное копирование и защита от одновременного списания сверх остатка.

## Ограничения первой версии

Нет импорта, инвентаризации/списаний, автоматического подключения весов и банков. Данные пока обслуживаются одним локальным сервером; вторая касса и удаленный доступ потребуют серверного размещения и авторизации. Windows/macOS-сборки и физическое оборудование должны пройти отдельную проверку. Перед использованием в магазине проведите тесты на копии данных.
