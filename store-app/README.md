# Nile Store 2.0

Локальный учет магазина для Windows 10 Pro и macOS. Интерфейс: русский, английский, арабский с RTL. Данные хранятся в SQLite на компьютере; интернет для работы не требуется. Одна касса, без налогов, ролей и смешанной оплаты.

## Как обновить первую версию и сохранить товары

1. В старой программе нажмите «Резервная копия» и сохраните полученный файл отдельно.
2. Остановите старую программу: `Control + C` в ее Терминале. Закройте старую вкладку браузера.
3. Скачайте свежий ZIP репозитория и распакуйте в новую папку. **Не удаляйте папку данных `.retail-store` в вашем профиле.**
4. Запустите новую версию из ее папки `store-app`: `python3 server.py` на Mac или `py -3 server.py` на Windows. Откроется версия **2.0.0** (номер есть в «Настройках»).
5. Товары, партии, курсы и старые чеки сохранятся автоматически. Перед изменением формата базы создается файл `before-upgrade-…sqlite`.
6. Перед первой новой продажей откройте «Кассовые смены» и укажите фактический размен в каждой валюте. Старые продажи остаются в отчетах и не добавляются в новую смену.

Обновление **не очищает тестовые продажи**. Для проверки на чистой базе используйте другую папку `STORE_DATA_DIR`. Старую программу после обновления базы не запускайте; для отката используйте отдельную копию `before-upgrade` и соответствующую старую версию приложения.

## Установка и запуск значком

### Без установленного Python

Автоматическая сборка: GitHub → **Actions → Build Nile Store desktop → последний успешный запуск → Artifacts**. Скачайте вариант своей системы:

- **Windows X64**: распакуйте архив, запустите `NileStore-Setup-Windows.exe`. Установщик создает значки в меню «Пуск» и на рабочем столе. Удаление приложения сохраняет базу в профиле.
- **macOS ARM64**: для Mac с Apple Silicon (M1/M2/M3/M4 и новее).
- **macOS X64**: для Mac с Intel. Внутри — `Nile Store.app`; перенесите в «Программы».

Для скачивания Artifacts может потребоваться вход в GitHub. Сборки не подписаны коммерческим сертификатом и не нотарифицированы Apple; системы могут показывать предупреждения. Успешная сборка не заменяет проверку на вашем компьютере и принтерах. При ошибке Actions скачайте исходники и используйте способ ниже.

### Из исходников, с Python 3.10+

Официальный Python с python.org включает Tkinter для окна запуска и установки.

- **Mac**: запустите `Install-Mac.command`. Установщик создаст `~/Applications/Nile Store.app` и откроет эту папку. Дальше запускайте приложение двойным нажатием. Если `.command` не запускается из Finder, один раз выполните `bash Install-Mac.command` в Терминале из папки `store-app`.
- **Windows**: запустите `Install-Windows.cmd`. Создаются значки на рабочем столе и в меню «Пуск». Исходники копируются в `%LOCALAPPDATA%\Nile Store`.
- При обновлении из исходников закройте приложение и снова запустите установщик из нового ZIP. Он обновляет файлы программы, сохраняя базу.

Окно Nile Store запускает локальный сервер и открывает браузер. Оно должно оставаться открытым; кнопка «Stop / Завершить» останавливает программу и делает копию. Повторное нажатие значка открывает уже работающую версию. Для обновления сначала завершите предыдущую.

Резервный запуск через Терминал: `python3 server.py` (Mac) / `py -3 server.py` (Windows). Без браузера: `python3 server.py --no-browser`. По умолчанию порт 8765; другой порт: `--port 8766`. Сервис слушает только текущий компьютер.

## Товары, партии и закупки

Создайте товар: название как оно должно печататься, единица (шт. / кг), продажная цена USD, минимальный остаток. Штрихкод производителя можно ввести сканером; пустое поле создает собственный восьмизначный код. Название, код, цену и минимум можно менять; единица после создания фиксируется. Старые чеки не меняются.

Каждое поступление — новая партия с количеством, закупочной ценой за штуку / кг **в EGP**, поставщиком и номером документа. Поставщики повторно предлагаются при вводе. FIFO идет по времени поступления и номеру партии. Программа показывает закупочные цены каждой партии и их пересчет в другие валюты.

Список «Пора заказать» показывает товары с остатком не выше минимума, включая нулевой остаток. Доступен CSV. Стоимость склада EGP = сумма оставшихся количеств партий × их закупочные цены.

## Инвентаризация и списания

- **Пересчет**: введите фактический остаток и причину. Недостача списывается по FIFO. Для излишка укажите закупочную цену EGP: создается отдельная партия.
- **Списание**: введите количество к списанию и причину (например, повреждение или собственное использование).
- Нулевой фактический остаток допустим. Отрицательные остатки запрещены. Если остаток успел измениться после открытия экрана, операция отклоняется: обновите экран и пересчитайте.
- Журнал сохраняет поступления, продажи, отмены, пересчеты и списания. Складские потери показаны в журнале; они не входят в показатель валовой прибыли **от продаж**.

## Кассовые смены

Откройте смену, введя фактический размен отдельно для USD/EUR/EGP/RUB. Разрешена одна открытая смена. Продажи без открытой смены блокируются.

Ожидаемые наличные = размен + наличные продажи − отмены наличных продаж + внесения − изъятия. Внесения / изъятия оформляются с причиной. Карта EGP и переводы RUB показаны отдельно и не увеличивают ящик наличных.

При закрытии пересчитайте каждую валюту. Программа покажет ожидаемую сумму, фактическую и расхождение. Итог закрытой смены сохраняется неизменным, можно выгрузить CSV. Автоматически создается резервная копия.

## Продажи, оплата и отмена ошибки

Сканер QW2100 должен работать как USB-клавиатура с Enter после кода. Сфокусируйте поле сканирования либо найдите товар по названию. Для весового товара введите вес до 0,001 кг.

| Валюта | Наличные | Карта | Перевод |
|---|---|---|---|
| USD | Да | — | — |
| EUR | Да | — | — |
| EGP | Да | Да | — |
| RUB | Да | — | Да |

Скидки в процентах / суммой доступны для строки и всего чека. Фиксированная скидка — в валюте оплаты; перепроверьте ее при смене валюты. Наличные: сдача в той же валюте; пустое поле полученной суммы означает точную оплату. Для перевода кассир подтверждает получение. Банковского подключения нет.

В отчетах доступна **отмена ошибочного чека**, пока открыта смена. Укажите причину и подтвердите, что деньги уже возвращены отдельно. Программа **не отправляет банковский возврат**. Исходный чек сохраняется, товар возвращается в исходные партии FIFO. Повторная отмена запрещена.

В отчет добавляется отрицательная корректировка **на дату отмены**, с исходными курсами. Старая продажа остается на исходную дату. Деньги корректируются в текущей смене, итог прошлой закрытой смены остается прежним. Если банк / сервис не вернул комиссию, она остается расходом. Отмена целого ошибочного чека не реализует частичные покупательские возвраты.

## Валюты, округление и комиссии

Курс — количество единиц EUR/EGP/RUB за **1 USD**. До первой продажи сохраните реальные курсы; исходные единицы — заглушки. Закупочная цена EGP и продажная цена USD фиксированы; остальные отображения пересчитываются.

Перед изменением курса или округления открывается таблица старых и новых цен. После подтверждения изменившиеся ценники попадают в список замены. История продаж не пересчитывается.

Округление задается отдельным шагом для EUR/EGP/RUB (например, 0,50, 1 или 5). До ближайшего шага, ровно половина — вверх. USD фиксирован до центов. Округляется **цена за единицу** одинаково на ценнике и кассе, затем сумма строки до центов, скидка строки и скидка чека. Весовая покупка может иметь дробную итоговую сумму даже при округленной цене за кг.

Комиссии карты (EGP) и переводов (RUB): процент и фиксированная сумма за платеж. Это расход магазина; сумма покупателя не увеличивается. Правило и комиссия сохраняются в продаже. Изменение настроек не меняет старые продажи. При нулевом чеке комиссия равна нулю.

## Отчеты

Период включительно по локальному времени компьютера, фильтры валюты и способа оплаты, независимая валюта отображения (по умолчанию EGP), CSV.

- Выручка после скидок.
- Себестоимость по реально списанным партиям FIFO.
- Валовая прибыль = выручка − себестоимость.
- Комиссии.
- Прибыль после комиссий = валовая прибыль − комиссии. Это не чистая прибыль: аренда и другие расходы не учтены.

Пересчет каждого события использует **курс на момент исходной продажи**. Отмена видна отдельной строкой; при попадании продажи и отмены в период их выручка и себестоимость взаимно погашаются. Комиссия погашается только при подтвержденном возврате комиссии. Старые продажи первой версии имеют нулевую комиссию и не привязаны к сменам.

## Чеки и массовые ценники

XP-233B: начальный размер **38 × 25 мм**. XP-N160II: измеренная лента около 78 мм, начальная полезная ширина чека 70 мм. Размеры и название магазина меняются в настройках и входят в копию базы.

В «Ценниках» выберите количество копий каждого товара либо заполните по остаткам (для кг — одна этикетка). Можно печатать только требующие замены. Не более 1000 этикеток за операцию, каждая на отдельной странице. После успешной печати нажмите **«Подтверждаю, что этикетки напечатаны»**. При отмене печати закройте окно — отметки сохранятся. Подтверждение означает замену всех старых ценников этого товара; программа не проверяет физическую замену.

Печать через системный диалог браузера, на Mac можно сохранить PDF. Масштаб 100%, колонтитулы отключены, бумага в драйвере соответствует шаблону. Обычные подробные чеки, без налоговой интеграции. Code 39 кодирует латинские заглавные буквы и цифры; код производителя при печати также представлен в Code 39. Длинный код на маленькой этикетке может не считываться — увеличьте ширину и проверьте сканером.

**USB-оборудование, арабская физическая печать, подача этикеток и Windows/macOS-инсталляция требуют проверки на вашем компьютере.** Linux-проверки и автоматические сборки не заменяют ее.

## Резервные копии и восстановление

Данные: `~/.retail-store/store.sqlite` (на Windows `.retail-store` в профиле). Они не лежат в папке приложения. Для изолированной тестовой базы — `STORE_DATA_DIR` на другую папку.

Копии создаются при запуске, раз в 24 часа непрерывной работы, при закрытии смены, при завершении через окно приложения и вручную. Локальные копии: `.retail-store/backups`. Дополнительно укажите **существующую** папку внешнего диска или уже синхронизируемую облачную папку. В оконной версии доступен выбор папки. Программа не подключает облачный аккаунт сама. При недоступности диска сохраняется локальная копия и выводится предупреждение. Старые копии автоматически не удаляются.

Кнопка «Скачать файл копии» сохраняет SQLite средствами браузера. Восстановление: закройте смену → «Настройки» → выберите `.sqlite` → введите `RESTORE`. Проверяются формат, целостность и версия, затем создается локальная страховочная копия `before-restore-…sqlite`. Все текущие данные заменяются выбранной копией; шаблон печати восстанавливается тоже. Язык интерфейса хранится отдельно в браузере. Перед реальной работой проверьте восстановление на отдельной тестовой базе.

## Проверки и сборка для разработчика

```sh
python3 -m unittest discover -s tests -v
python3 desktop.py --self-test
```

Браузерный сценарий `tests/browser.cjs` требует Playwright и Chromium; запускайте только против **пустой изолированной** базы на порту 8767 (скрипт создает продажи и восстанавливает базу). Не направляйте его на рабочие данные.

```sh
STORE_DATA_DIR=/tmp/nile-browser python3 server.py --no-browser --port 8767
node tests/browser.cjs
```

Сборка на целевой ОС: `python -m pip install pyinstaller==6.16.0`, затем из `store-app`: `python -m PyInstaller packaging/NileStore.spec --noconfirm`. На Windows установщик собирается Inno Setup 6 из `packaging/windows-installer.iss`. CI проверяет расчеты, миграцию и запуск упакованного приложения в режиме `--self-test`; файлы публикуются как Artifacts. Автоматическое обновление из интернета не включено.
